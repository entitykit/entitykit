# EntityKit 0.1.0-alpha.1

EntityKit 0.1.0-alpha.1 is the first public alpha of an Entity
Framework-inspired ORM for TypeScript.

## Included

- Ordinary TypeScript entities and explicit fluent mapping
- Typed queries, change tracking, transactional saves, and relationships
- Source-controlled migrations and the EntityKit CLI
- SQLite, Postgres, and MySQL providers
- Provider-neutral recording test doubles

## Install

```sh
npm install @entitykit/core@alpha @entitykit/sqlite@alpha
npm install -D @entitykit/cli@alpha
```

Install `@entitykit/postgres` with `pg`, or `@entitykit/mysql` with `mysql2`,
when the application uses those providers.

## Alpha boundary

EntityKit requires Node.js 22.13 or newer. APIs may change before 1.0. Database
DDL, isolation, locking, and schema inspection still differ by provider. Review
generated migrations before applying them.

Read the
[compatibility guide](https://github.com/entitykit/entitykit/blob/v0.1.0-alpha.1/docs/compatibility.md)
and
[migration guide](https://github.com/entitykit/entitykit/blob/v0.1.0-alpha.1/docs/migrations.md)
for the exact boundaries.

## Verification

This release is accepted as one six-package artifact family. Its release gate
covers Node.js 22.13 and 24, live Postgres 18 and MySQL 8.4, runtime coverage,
mutation testing, and clean CommonJS, ESM, type, CLI, and package-consumer
paths.
