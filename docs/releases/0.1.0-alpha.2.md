# EntityKit 0.1.0-alpha.2

EntityKit 0.1.0-alpha.2 turns the application data-source lifecycle into a
first-class public API and adds the first framework integration.

## Highlights

- `DbContext` can receive an application-scoped data source directly.
- `EntityKitDataSource`, context-factory, retry, and provider configuration
  types are available from the main `@entitykit/core` entry point.
- `@entitykit/nestjs` provides `forRoot`, `forRootAsync`, `forFeature`, typed
  injection tokens, automatic context disposal, and application-shutdown
  ownership for NestJS 12.
- The Next.js 16 + Postgres Lantern Journal demo covers Server Components,
  Server Actions, a Route Handler, migrations, and production Playwright flows.
- The documentation now begins with one explicit lifecycle and routes newcomers
  into focused usage, framework, compatibility, and API guides.

## Install

```sh
npm install @entitykit/core@alpha @entitykit/sqlite@alpha
npm install -D @entitykit/cli@alpha
```

For NestJS 12:

```sh
npm install @entitykit/core@alpha @entitykit/postgres@alpha @entitykit/nestjs@alpha \
  pg @nestjs/common@^12 @nestjs/core@^12 reflect-metadata rxjs
```

Install `@entitykit/mysql` with `mysql2` for MySQL. Keep every EntityKit package
on the same exact alpha version.

## Framework boundary

`@entitykit/nestjs` is native ESM and targets NestJS 12 on Node.js 22.13 or
newer. EntityKit remains a Node-only database library; the Next.js example uses
the Node runtime and does not imply Edge, browser, or general bundler support.

Create one data source per application process or warm instance, create a fresh
context per request or unit of work, dispose every context, and close the source
only during application shutdown.

## Verification

This release is one seven-package artifact family. Its gate covers Node.js
22.13 and 24, packed Node16 and NodeNext consumers, CommonJS and ESM runtime
paths, Nest module lifecycle, the installed CLI, one shared core instance,
live Postgres 18 and MySQL 8.4, and the Next.js production browser flow.
